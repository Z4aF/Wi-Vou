# Wi-Vou RFID Voucher System

An ESP32-based RFID voucher distribution system with TFT display and PHP/MySQL backend.

## Features
- RFID registration
- Voucher claiming
- TFT UI
- Keypad input
- Usage limit system

## Technologies Used
- ESP32
- MFRC522 RFID
- TFT_eSPI
- PHP
- MySQL

## Setup
1. Import SQL database
2. Put PHP files inside XAMPP htdocs
3. Upload ESP32 code
4. Connect ESP32 to WiFi
